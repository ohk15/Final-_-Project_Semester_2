🚀 Overview
This project is a complete end-to-end data processing and visualization application built in Python. It automates the workflow of fetching live data via an API, securely storing and managing it using a local SQLite database, and rendering insightful visual charts to analyze the results.

🛠️ Key Features
Automated Data Retrieval: Connects to an external API to fetch real-time data efficiently.

Database Management: Utilizes SQLite to store, structure, and query the dataset locally.

Data Visualization: Generates clean, analytical charts to represent data trends clearly.

Version Control: Managed via Git and hosted publicly on GitHub for seamless collaboration and deployment.
